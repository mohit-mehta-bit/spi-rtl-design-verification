# spi-rtl-design-verification



## Overview

Designed and verified an SPI communication interface using
Verilog/SystemVerilog RTL.

The project implements SPI Master and Slave communication and
verifies data transfer between the Master and Slave using a
SystemVerilog testbench.

## RTL Design

- SPI Master
- SPI Slave
- Serial data transmission and reception
- MOSI and MISO handling
- SCLK generation
- Chip Select control
- 8-bit data transfer

## Verification

- Verified SPI Master-to-Slave data transfer
- Verified Slave-to-Master data transfer
- Checked MOSI and MISO data
- Verified SCLK and Chip Select operation
- Verified correct serial data transmission and reception
- Analyzed simulation waveforms

## Tools

- Verilog
- SystemVerilog
- EDA Playground
- Xilinx Vivado
